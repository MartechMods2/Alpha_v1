# Alpha reliability and moderation repair

The status compatibility patch addresses the pinned Baileys 7.0.0-rc14 missing top-level status handler (upstream WhiskeySockets/Baileys issues 2858 and 2903). It acknowledges live/offline statuses through the existing processor and routes encrypted group statuses through normal message decryption, so moderation can see them. The build fails if the expected dependency version/anchors change. CI applies the same patch. Keep this patch under review when changing Baileys.

Group statuses require a group-status meta node on admin revocation. Alpha now supplies it for recognized group-status content, preserving the original message author/key. Ordinary message and status-mention notification deletion remains separate; Alpha cannot remove a member's personal Status from all their contacts. A resolved send is a deletion request, not proof that every phone applied it. Keep the existing strike policy and permission checks.

Anti-bot now removes administrator-confirmed blocked accounts when they post or rejoin and supports immediate `antibot block @member` removal. It checks current membership, PN/LID aliases, protected roles and Alpha's current admin permission. A denied/timeout result never claims successful removal. It does not infer bot identity from message ID prefixes, fast replies, or invoking an AI; silent/disguised bots remain undetectable. `antibot allow @member` clears known aliases; `antibot scan` reports blocked accounts still present. Uncertain native bot markers remain advisory.

Transient moderation maps now have TTLs and entry limits. Media buffers are capped at 8 MiB / 256 entries and expire after five idle minutes. High-quality link thumbnail generation is disabled to reduce optional processing. This limits potential retention; it is not a measured promise of a particular RSS reduction or response time. The deployment replaces the old process and releases its in-memory allocations without deleting stored settings, authentication or member history.

Everyday replies preserve body text without the repeated branded frame. Social fallback prompts avoid claiming that members are online. AI style instructions favor concise, contextual replies and prohibit pretending that an unconfirmed administrative action succeeded. Group Pulse reports enforcement state and admin readiness.

Shutdown logs now identify safe subsystem/signal names rather than hiding all failure context. They do not print exception payloads, message bodies or credentials.

Validation: synthetic group-status receive/offline routing and ACKs, group-status revoke metadata, ordinary deletes, PN/LID bot enforcement, admin denial and session-stop safeguards; existing regression suite; bounded synthetic ingestion load; dashboard production build. No real group members are removed by tests. Live phone-to-phone status deletion and stable operation beyond 50 minutes require production observation. UptimeRobot must monitor `/readyz`, rather than just the homepage. Render's liveness check should not turn an invalid WhatsApp session into an endless restart loop.

The second pass removed unused `wa-sticker-formatter` and the legacy `genius-lyrics-api` fallback, eliminating their old Axios/Jimp/jsdom/request dependency trees. Lyrics now handles empty search results, awaits delivery, avoids echoing provider errors, removes 4,001 invisible characters and has no artificial three-second pause. Compatible direct and transitive security updates are verified with the full regression suite. Dependency advisories and external-provider changes remain ongoing maintenance, not a claim that every possible vulnerability is eliminated.

Final hardening also upgrades the dashboard to the patched React Router 7 line (the used declarative routing API is retained) and pins patched basic-ftp/minimatch interfaces for their older parents. Compatibility checks cover the parent's minimatch calling convention, FTP Client method availability, and dashboard route matching. Docker and npm start commands apply the same pinned status patch. The final Bun dependency audit returned an empty advisory set; this is a time-specific advisory check, not proof of absence of undiscovered issues.

A globally blocked sender no longer bypasses group moderation: the global reply/command block is applied after safety enforcement.
