The creator can post these with `$auraannounce`. Anyone can read each page with `$auraguide 1`, `2` or `3`. Check `$aurasystem status` before announcing activation.

08:00, 14:00 and 20:00 Africa/Lagos. Each slot shares ONE 20,000-Aura code across selected groups. $redeem CODE — first valid claim wins globally. One scheduled win per person daily; codes expire after 30 minutes. Missed offline slots are skipped.

$auraguide 2 — spending, shop and Evo

```text
╭─ ✨ *AURA · RANKS & FAIR PLAY*

*THREE SEPARATE TRACKS*
Aura is spendable. Lifetime XP is permanent progress and is NOT reduced by spending or normal losses. Ranked RP measures optional competition. Existing message ranks and old virtual coins remain separate.
XP ranks: Rookie 0, Bronze 500, Silver 2,000, Gold 5,000, Platinum 12,000, Diamond 25,000, Master 50,000, Grandmaster 100,000, Legendary 200,000.
$aurarank / $aurabadges / $auraboard

*RANKED DUELS — FREE ENTRY*
$auraduel @member → opponent uses $auraaccept → each player has one $auraanswer <answer> attempt. Invitations/questions expire in two minutes. First correct answer wins: +30 RP; opponent −15 RP. First daily loss is protected, promotion gives two loss shields, and Bronze provides a 300-RP floor once reached. No correct answer or expiry: no RP/Aura loss.
Ranked seasons follow Lagos calendar months. On the first next-season result, RP becomes half the old value capped at 300; lifetime XP, Aura and cosmetics remain. At most three scored matches per opponent pair and ten per member daily.

*PENALTIES & APPEALS*
Only the creator reviews Aura penalties. First incident per Lagos day: warning, no deduction. Later reviewed incidents: up to 1,000 each, capped at 5,000 requested penalty Aura daily; balance never goes negative. Each financial penalty removes 10 conduct points. $daily restores 1 conduct point, up to 100. Below 60 blocks scored duels; below 40 blocks paid features.
No Aura fines for being quiet, normal losses, wrong quiz answers or failed APIs. No random theft or cash betting. Existing moderation rules still apply.
Receipts are sent privately. $auraappeal RECEIPT <reason> requests review; the creator can reverse mistaken penalties once. Creator gifts/custom coupons share a 500,000-Aura daily budget.

When Aura is OFF, normal commands use their ordinary permissions/quotas without Aura fees. New Aura rewards, purchases, transfers, duels and drops pause; balances remain saved. Already-running requests may finish and settle; stale reservations are refunded. $aurasystem status checks activation.
```
